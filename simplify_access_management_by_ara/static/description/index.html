A ASAM Studio

ARA Simplify Access Management (ASAM)

A centralized solution to manage field, model, menu, record, and UI permissions while enabling complete White-Label System Debranding.

Introduction

Complete Access Management Without Coding

ASAM (ARA Simplify Access Management) is designed to replace complex Odoo permission setups. Through a single, streamlined profile menu, administrators can configure granular access down to micro-level UI elements.

The module automatically syncs active security rules to connected user sessions in real time via WebBus without requiring server restarts.

Micro-Level Controls

Configure specific fields, buttons, and form tabs.

White-Labeling

Remove Odoo branding and apply custom brand assets.

Real-time Reload

Changes take effect immediately on user screens.

Multi-Company

Enforce rules by user, group, or active company.

Module Capabilities

Core Features of ASAM

Model & Field Controls

Mark fields as Read-Only, Hidden, or Required. Prohibit Create, Edit, Delete, Duplicate, Archive, Import, and Export per model.

Record Domain Rules

Restrict data rows using dynamic domain expressions (supports user, uid, company_id, company_ids, and time).

Menu & UI Restrictions

Hide navigation menus, specific action buttons, form tabs, search filters, group-bys, and view types (Kanban, List, Gantt, Pivot, etc.).

Chatter Controls

Disable Chatter widgets globally or per model. Hide Send Message, Log Note, and Schedule Activity options as needed.

System Security

Restrict Developer Mode (?debug=1), block module installation/upgrades, disable XML-RPC / JSON-RPC APIs, or enforce Deny Login.

White-Labeling / Debranding

Hide "Powered by Odoo" footers, customize browser titles, change backend URL prefixes (e.g., /app), and upload custom Favicons.

Step-by-Step Guide

How to Use ASAM

1. Create Profile

Navigate to SAM Profile, create a record, and assign target Users, User Groups, or Companies.

2. Configure Rules

Select the appropriate tab (Model Rules, Field Rules, Record Rules, etc.) to set specific data and UI restrictions.

3. Setup Debranding

To white-label the platform, enable Hide Odoo Branding, enter your custom Brand Name, URL Prefix, and upload a Favicon.

4. Save & Apply

Click Save. Restrictions sync instantly to assigned user sessions without requiring server restarts.

Record Domain Filter Example

To restrict users so they can only view records assigned to them within their active company, use this expression under Record Rules:

[('user_id', '=', user.id), ('company_id', 'in', company_ids)]
